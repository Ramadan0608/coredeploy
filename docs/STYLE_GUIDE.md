# Core Deploy Editorial Standards

## Writing Style

- Use official Apple terminology.
- Use official Jamf terminology.
- Prefer active voice.
- Explain acronyms on first use.
- Include prerequisites.
- Include troubleshooting.
- Include best practices.
- Include references.

## Naming

Use lowercase filenames.

Good:

apple-business.md

Bad:

01-introduction.md

Good:

platform-sso.md

Bad:

PlatformSSO.md
